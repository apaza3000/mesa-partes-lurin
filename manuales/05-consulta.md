# Manual de usuario — Rol Consulta

El rol **Consulta** es de solo lectura: permite buscar expedientes y ver trazabilidad, sin modificar datos.

## 1. Buscar expediente
Ruta: **CONSULTAS → Buscar expediente**.

1. Ingrese el código del expediente o número de documento.
2. Pulse **Buscar**.
3. Revise los datos y el estado actual.

![Buscar expediente](capturas/05-consulta.png)

## 2. Trazabilidad
Ruta: **CONSULTAS → Trazabilidad**. Historial completo del expediente.

![Trazabilidad](capturas/05-trazabilidad.png)

## 3. Perfil
Cambio de contraseña en **SISTEMA → Mi perfil**.

## 4. Notificaciones
Campana en la barra superior (si tiene notificaciones asignadas).
