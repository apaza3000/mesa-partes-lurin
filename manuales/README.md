# Manuales de usuario

Carpeta con los manuales por rol del Sistema de Trámite Documentario y Mesa de Partes.

## Archivos
- `00-general.md` — manual general (acceso, navegación, perfil, consulta, trazabilidad, notificaciones, instalación).
- `01-administrador.md` — rol Administrador.
- `02-mesa-de-partes.md` — rol Mesa de Partes.
- `03-responsable-area.md` — rol Responsable de área.
- `04-usuario-area.md` — rol Usuario de área.
- `05-consulta.md` — rol Consulta.

## Imágenes
Las capturas de pantalla se guardan en la subcarpeta `capturas/` con los nombres referenciados en cada manual (ej. `capturas/00-login.png`). Mientras no se agreguen, los enlaces quedan listos para colocarlas.

### Convención de nombres
`{nn}-{pantalla}.png` donde `nn` es el prefijo del manual (00, 01, …) y `pantalla` describe la vista (login, dashboard, usuarios, etc.). Formato PNG, ancho recomendado 1280 px.
